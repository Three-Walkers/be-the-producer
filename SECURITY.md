# Reporting a security vulnerability

If you can read another project’s files, expose a model provider key, or make the studio run an action without the producer’s approval, please [report the vulnerability privately](https://github.com/Three-Walkers/be-the-producer/security/advisories/new). You can write in English or 简体中文.

Include the affected commit or version, where the studio was running, the shortest steps that reproduce the issue, and what another person could access or change. Use a sample project and dummy credentials. If a real credential was exposed, revoke or rotate it with its provider.

Use the private report for follow-up questions, fixes, and discussion of disclosure. For problems without a security impact, use the [public issue tracker](https://github.com/Three-Walkers/be-the-producer/issues/new/choose).

## 中文报告方式

如果你能读取其他项目的文件、看到模型服务密钥，或绕过制作人确认执行操作，请[私下报告漏洞](https://github.com/Three-Walkers/be-the-producer/security/advisories/new)。请写明版本或提交、运行环境、最短复现步骤，以及能访问什么数据或执行什么操作。请使用示例项目和虚构凭据。若真实密钥已经泄露，请及时在服务商处撤销或更换。复现细节和后续沟通都可留在这份私密报告中。
