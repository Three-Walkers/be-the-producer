# Accessibility

We want producers to be able to describe a game idea, follow a studio conversation, and review work using a keyboard or assistive technology.

This statement covers the studio’s browser interface and the documentation on GitHub. One known limitation affects art reviews. An image preview’s alternative text identifies the deliverable and file, so a screen reader user can find the asset but may still need a description of its visual content. We have not verified every workflow with a screen reader. Each generated game also needs its own accessibility playtest.

If something blocks you, [report an accessibility barrier](https://github.com/Three-Walkers/be-the-producer/issues/new?template=bug_report.md). Tell us what you were trying to do, which screen or document you were using, and where you got stuck. Include the browser, device, or assistive technology if relevant. A text report is enough.

## 无障碍反馈

我们希望制作人可以用键盘或辅助技术表达创意、跟进讨论并审阅交付物。本说明适用于工作室的浏览器界面和 GitHub 上的项目文档。当前美术预览的替代文本会标出交付物和文件，使用读屏软件的人仍可能需要他人描述画面内容。部分流程尚待读屏验证，每款生成的游戏也需要单独试玩。

如果某一步难以操作，欢迎用中文[反馈无障碍问题](https://github.com/Three-Walkers/be-the-producer/issues/new?template=bug_report.md)。写明想完成的任务、所在页面和卡住的位置即可。纯文字反馈就足够。
